# Postman Collection for Golf Club API

This directory contains Postman collections and environments for testing the Golf Club API.

## Quick Start

1. **Import Collection**
   - Open Postman
   - Click "Import" 
   - Select `Golf Club API.postman_collection.json`

2. **Import Environment (Optional)**
   - Click "Import"
   - Select `workspace.postman_globals.json`
   - Set as active environment

3. **Set Base URL**
   - If not using environment, manually set: `http://localhost:8080`
